# 27B推理路由

本模块负责27B模型的推理调度和回答编排：

- OpenAI接口协议的流式转发；
- 请求优先级、排队、取消和超时；
- 27B GPU任务的准入和租约；
- 断线清理和幽灵请求回收；
- Elasticsearch业务知识检索、会话记忆和欢迎语本地化；

本模块不保存模型权重，也不执行ASR、OCR或媒体任务编排。

## 配置边界

- `config/prompts.toml`：所有发送给模型的身份、检索、摘要、本地化、图片和核价提示词，
  其中人工服务文案由27B生成，Router只输出结构化事件；
- `config/knowledge-policy.toml`：检索词表、会话分类词表和知识上下文标签；
- `config/router.env`：地址、模型、并发、超时和缓存等运行参数。

代码只负责加载、校验和执行这些配置。HTTP协议字段、日志、异常信息和正则解析逻辑仍保留
在代码中，它们不属于提示词或业务知识。

源码直接位于当前目录，单元测试和测试Web位于`qwen-llm/tests/`，服务名为
`gta-ai-router.service`。
